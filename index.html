FAQ

Common questions.

Does Campaign Momentum cost anything?

The board itself is free, with no subscription and no account required. AI suggestions are optional and billed per use directly by Anthropic through your own API key, typically a fraction of a cent per suggestion.

Do I need a Google account or an API key to use it?

No. The board works fully in your browser with nothing connected. A Google Sheet is only needed if you want your board to sync across devices, and an API key is only needed for AI suggestions.

Where is my data stored?

By default, only in your browser's local storage on that one device. If you connect a Google Sheet, your data lives in a spreadsheet you own — never on our servers.

Which AI provider does Campaign Momentum use?

Campaign Momentum is built on Anthropic's Claude. It doesn't currently support other AI providers.

Can more than one person use the same board?

Yes, if you connect a shared Google Sheet — anyone with the Web App URL can view and update the same board.
